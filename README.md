# Baixar Coisas

Ferramentas em Python para downloads e processamento de arquivos.

## Estado

Projeto experimental em evolução.

## Observações

- Configure suas próprias credenciais e caminhos localmente.
- Arquivos de sessão, downloads, logs e configurações pessoais não fazem parte do repositório.

## Tecnologias

- Python
- FFmpeg
- Downloads HTTP e mídia
